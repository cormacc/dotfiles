* Intent

Give my daughter a reliable, adult-free way to play Minecraft with the Star Worm Equestrian Mod (SWEM). Decide between a local install and a LAN server, state plainly which of her devices can take part, and keep the setup out of the Nix flake because the Pi is not Nix-managed and the world is disposable.

* Summary

*Level:* MVP · *Tests:* smoke · *Docs:* README

Decision: install everything locally on the Pi 500+ (Prism Launcher, pinned NeoForge 1.21.1 instance, SWEM + dependencies), following a kid-friendly HTML install guide written first so parent and daughter can work through it together. No server, no backup, nothing in the flake. Only the Pi 500+ (and, as a fallback, the Chromebook via its Linux container) can run SWEM; the Nintendo Switch and the Android tablet cannot, under any architecture.

** Scope

*** In scope
- Prism Launcher on the Pi 500+ via Pi-Apps, with the Mesa GL-version override Pi-Apps configures.
- One pinned instance: MC 1.21.1, NeoForge, SWEM 1.21.1-1.6.12, GeckoLib, Player Animator; 6 GiB max heap; entity shadows off.
- A viability gate (median F3 FPS ≥ 25 with a SWEM horse in view) before any effort on polish, with ordered fallbacks.
- A desktop shortcut that launches the instance directly and carries the Mesa override.
- A kid-friendly HTML install guide with links (=2026-09-09-setup-minecraft-with-the-swem-mod/install-guide.html=), written before the install and revised after the viability gate; it doubles as the reinstall how-to.

*** Out of scope
- Any Minecraft server (on =nas= or elsewhere), Geyser/Floodgate or any Bedrock bridge.
- Serving the Switch or the Android tablet: SWEM is a Java Edition mod required client-side; Geyser cannot translate modded content (Geyser FAQ).
- World backups or snapshots: the world is declared disposable.
- Any change to the Nix flake, NixOS hosts, or Home Manager.
- Multiplayer; a second player would need their own Java licence and a server (see Follow-ups).

** Acceptance

*** Core functionality
- [ ] From the Pi 500+ desktop, one launcher entry starts Minecraft 1.21.1 + NeoForge + SWEM (+ GeckoLib, Player Animator) with no password prompt after the first login.
- [ ] In a world, a SWEM horse spawns.
- [ ] A SWEM tack item can be equipped on that horse.
- [ ] Median FPS ≥ 25 (F3 overlay) with a SWEM horse in view at the pinned settings.
- [ ] After a Pi reboot the same world opens with progress intact.
- [ ] Minecraft, NeoForge, SWEM and dependency versions are pinned in the Prism instance; nothing auto-updates.
- [ ] =install-guide.html= opens in a browser on the Pi and its steps match the settings that passed the gate.
- [ ] Every hyperlink in =install-guide.html= returns HTTP 200 (or 403 from CurseForge's bot filter, which is browser-reachable).

*** Edge cases
- [ ] The direct-launch shortcut still starts the game after the system =org.prismlauncher.PrismLauncher.desktop= is rewritten without the Mesa override (the shortcut carries the env itself).

*** Anti-criteria
- Must not: expose any port to the internet.
- Must not: add a Geyser/Bedrock bridge or touch the Switch or tablet.
- Must not: depend on "latest" for MC, loader, or any mod.
- Must not: add anything to the Nix flake or NixOS host configs.

** Decisions
- Chose A (local single-player on the Pi 500+, no backup) :: single player, disposable world, one machine, works with the LAN or =nas= down; the client renders SWEM locally regardless of where the world lives, so a server would not reduce the Pi rendering risk. Rejected:
  - B (NeoForge server on =nas= via the nix-minecraft flake, Pi as client): adds a second install whose SWEM/NeoForge versions must match the client exactly, a LAN dependency, and a =nas= rebuild; buys world safety and multiplayer that are not wanted now. Retained as the follow-up path if a second player appears; =nas= (NixOS 26.11, Intel N97, 30 GiB RAM, ZFS, Docker) is ample, and nix-minecraft packages NeoForge ≥ 20.4.240 (MC 1.20.4+), covering SWEM's 1.21.1 line but not its 1.20.1 Forge line.
  - C (server via =itzg/minecraft-server= in =homelab-compose.nix=): same objection as B; covers the older Forge 1.20.1 line too, less Nix-native.
  - Nightly backup of the world to =nas=: declined by the user; the world is disposable.
- Target the MC 1.21.1 / NeoForge / Java 21 line, not 1.20.1 Forge :: it is the actively developed line (latest =swem-1.21.1-1.6.12.jar= 2026-08-01 vs 1.20.1's last build 2026-05-15) and Prism ≥ 8.0 supports NeoForge. 1.20.1 Forge is the second fallback if 1.21.1 fails the FPS gate.
- Nothing in the flake :: the Pi runs Raspberry Pi OS and is not Nix-managed; this record is the durable home of the how-to.
- Pi 500+ is the primary client; the Lenovo IdeaPad Flex 3 Chromebook is a fallback only (its CPU family is unknown -- the model shipped with both MediaTek and Intel N-series; only Intel/AMD Crostini is credible for a modded Java client).

** Gotchas
- SWEM requires Java Edition; the household owns only Bedrock, so a Microsoft account with "Minecraft: Java & Bedrock Edition for PC" is a prerequisite. A child account needs family-group consent; single player never needs the Xbox multiplayer toggles.
- Pi-Apps' Prism installer patches =Exec=env MESA_GL_VERSION_OVERRIDE=3.3 prismlauncher= into the system =.desktop= and installs Temurin 8/17/21; Pi-Apps vouches for that override only up to MC 1.19.2, so 1.21.1 is empirically gated here.
- SWEM wiki: disable entity shadows or animations desync.
- The CurseForge site returns HTTP 403 to non-browser fetchers; version facts came from the Modrinth API, the SWEM wiki, and the CFWidget mirror (=2026-09-09-setup-minecraft-with-the-swem-mod/curseforge-files-2026-09-09.tsv=).

** Risks
- Pi 5 Mesa (v3d) with the 3.3 override may not sustain 25 FPS on 1.21.1 with GeckoLib entities. Mitigated by making the gate the first task, with fallbacks: Sodium (NeoForge build) → 1.20.1 Forge line → Chromebook via Crostini.
- Prism's CurseForge browser may be refused third-party download for one of the jars. Mitigated in-task: download in a browser and drop into =mods/=.
- A Microsoft child account may stall on the Xbox-profile step of the Java login. Accepted: first login is done with a parent present.
- The Chromebook fallback may be MediaTek-based and unviable. Accepted: it is only consulted if the Pi fails the gate.

** Follow-ups
- If a second player is wanted: revisit B (nix-minecraft NeoForge server on =nas=), which needs a second Java licence and a flake input; the research note in =2026-09-09-setup-minecraft-with-the-swem-mod/research-swem-devices-hosting.md= covers the hosting options.
