Minecraft with SWEM horses: install guide

This guide sets up Minecraft with the SWEM mod (it adds rideable, tackable horses) on the Pi 500+. Do the "Grown-up part" first. Then do the "Your part" together.

Grown-up part

These four steps need an adult, because they involve an account, money, and a first sign-in.

One honest note: Pi-Apps' own installer says its Raspberry Pi graphics fix is only checked to work up to an older Minecraft version (1.19.2), not our newer 1.21.1 with mods — so it might run slowly, or not at all, on the Pi. If that happens, the "If it is slow" box further down has the plan for what to try next.
  1. Add her to your Microsoft family group and give consent for her account, if she does not already have one in it. Microsoft explains the steps here: Set up Microsoft Family Safety.
  2. On her Microsoft account, buy "Minecraft: Java & Bedrock Edition for PC" at the official store page: minecraft.net. This is the edition that supports mods; the Bedrock edition you already own does not.
  3. Do not write her Microsoft password anywhere in this guide or on a sticky note. Type it together, at the keyboard, when asked.
  4. The first time her account signs in to Prism Launcher (in "Your part", step 6), stay with her: the first sign-in asks extra questions that a later sign-in will not.

Your part

Below you will set up one instance (instance: one self-contained copy of Minecraft, with its own version, mods, and settings, kept separate from any other copy) called SWEM.

1. Install Pi-Apps

  1. Open the Pi's terminal (terminal: a plain black window where you type commands instead of clicking).
  2. Type this line exactly and press Enter: wget -qO- https://raw.githubusercontent.com/Botspot/pi-apps/master/install | bash
  3. Wait until the window says the install has finished, then close it.

Source: Pi-Apps install page.

2. Install Prism Launcher from Pi-Apps

  1. Open Pi-Apps from the Pi's main menu.
  2. Click the "Games" category.
  3. Scroll down to find "Minecraft Java Prism Launcher" and click Install.
  4. Wait for Pi-Apps to say the install is finished.

Source: Pi-Apps: install Minecraft Java Prism Launcher.

3. Make the SWEM instance (1.21.1 / NeoForge)

  1. Open Prism Launcher: Menu > Games > Prism Launcher.
  2. Click "Add Instance…".
  3. Name the new instance SWEM.
  4. Choose Minecraft version 1.21.1.
  5. Choose NeoForge as the loader (loader: the extra program inside the instance that lets mods run). Do not choose Forge or Fabric.
  6. Click OK and wait for it to download.

Source: Prism Launcher wiki: Creating an Instance.

4. Add SWEM, GeckoLib, and Player Animator

  1. Right-click the SWEM instance and choose Edit…, then open the Mods tab.
  2. Click "Download mods" and choose the CurseForge tab.
  3. Search for SWEM, choose "Star Worm Equestrian (Upgrading Horses)", and pick the file made for Minecraft 1.21.1 and NeoForge: swem-1.21.1-1.6.12.jar.
  4. Search for GeckoLib and pick the newest file offered for Minecraft 1.21.1 and NeoForge.
  5. Search for Player Animator and pick the newest file offered for Minecraft 1.21.1 and NeoForge.
  6. Click OK and wait for all three to download and appear ticked (enabled) on the Mods tab.
If CurseForge shows an "Update" button next to a mod later on, leave it alone. These versions are chosen on purpose so everything keeps working together.

Source: CurseForge: SWEM (Star Worm Equestrian).

5. Turn on Java 21 and memory, then turn off entity shadows

This step assumes the Pi 500+'s 16 GB of memory. If your Pi has less memory than that, ask an adult before using the number below — a smaller Pi may need a smaller number here, or the game can freeze instead of starting.
  1. Right-click the SWEM instance, choose Edit…, then choose Settings in the list on the left, and open the Java tab.
  2. Tick the box titled "Java installation" — ticking it turns on custom Java settings for just this instance.
  3. Click "Auto-detect…" and choose an entry that shows version 21. Minecraft 1.21.1 will not start on an older Java version.
  4. If no entry shows version 21 (the Pi's own installer only promises Java 8 and 17 by default), click "Download Java" instead and choose 21 there.
  5. Tick the box titled "Memory".
  6. Set "Maximum memory allocation:" — programmers call this the heap (heap: the block of computer memory that Minecraft is allowed to use) — to 6144.
  7. Start the SWEM instance once, open Options…, then Video Settings…, and set "Entity Shadows" to Off. This stops the SWEM horses' animations from glitching.

Source: SWEM wiki: Installing Mods.

6. First launch

  1. Double-click the SWEM instance (or select it and click "Launch" in the toolbar) to start it.
  2. Sign in with her Microsoft account when asked (a grown-up should be there for this first time — see the Grown-up part).
  3. Once Minecraft opens, click Singleplayer, then Create New World, and wait for the world to load.

7. Make the desktop shortcut

  1. In Prism Launcher, right-click the SWEM instance and choose "Create Shortcut".
  2. Find the new shortcut on the desktop and try it once: it should start the SWEM instance directly, without opening Prism Launcher's main window first.
If it is slow (the game feels jerky or the numbers in the corner, F3, show low FPS), try these in order:
  1. Add the Sodium mod (the NeoForge build) to make Minecraft draw the screen faster.
  2. If that is still not enough, switch to the older 1.20.1 Forge version of SWEM instead.
  3. If that is still not enough, play on the Chromebook instead of the Pi.
This guide never asks for or stores a password. Type account details directly into Microsoft's or Minecraft's own sign-in screens, never into this file.
